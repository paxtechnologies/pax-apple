# Pax-approved installs (v0.8.33): apps pax-guard will NOT install or update for the
# everyday (Standard) account, on top of the lists pax-guard already keeps in
# guard_config.py (VPNs, Tor, proxies, unmanageable browsers, remote AI browsers and
# virtual machines: BYPASS_APPS, UNMANAGEABLE_BROWSERS, REMOTE_AI_APPS, VM_APPS) and the
# user's own Blocked apps. Those lists are reused as they are; this file only adds the
# kinds of app they don't cover: remote-desktop tools, rented-Mac / cloud-computer
# clients, mesh VPNs and a few proxy clients.
#
# Format (one rule per line; anything else is an error and pax-guard then refuses every
# install, fail closed):
#   [<category id>] <what the user reads after "Pax doesn't install ">
#   bundle <bundle ID>          exact match, case-insensitive
#   bundle <prefix>.*           every bundle ID starting with "<prefix>."
#   team <Team ID>              every app signed by that Apple Developer Team ID
#   name <App Name>             the app's folder or display name, case-insensitive
# Only Team IDs confirmed from a public source are listed (Tailscale: W5364U7YZB, from
# appcatalog.cloud and Tailscale's own system-extension entitlements). Everything else
# is matched by bundle ID prefix and name. An app found here can still be installed
# after the turn-off wait, with the Mac's administrator, like before 0.8.33.
