# Pax curated list (v0.5): "remote desktop" category. ON BY DEFAULT.
#
# Remote desktop and remote-access services, plus enterprise virtual desktops.
# Controlling another computer means browsing on a machine Pax doesn't filter,
# so these are blocked by default. Some people need them for work, so this is a
# separate category that can be switched off; switching it off waits like any
# other removal (the blocklist delay, 72 h by default), can be cancelled, and
# tells the accountability partner. Switching it back on is immediate.
#
# One domain per line, no inline comments. pax-dns blocks each entry and all its
# subdomains. pax-guard writes each entry and www.<entry> to /etc/hosts (exact
# names only), so known fixed host names are listed one by one as well.
# Self-hosted servers (RustDesk, Moonlight/Sunshine, VNC, RDP by IP address)
# can't be blocked by name; pax-guard's pf rules block the standard ports
# instead while this category is on.
# Every name below was checked on 2026-10-14 (apex names of services whose
# relays live on subdomains may not resolve themselves).
